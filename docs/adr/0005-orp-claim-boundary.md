# ADR 0005 - ORP Claim Boundary

## Status

Accepted

## Decision

ORP may be described as deterministic private overlay routing before it is described as a global anonymity network.

## Why

ORP already has a strong architectural idea and real implementation value. Calling it an anonymity network before multi-hop circuits, cover traffic, operator diversity, and audit gates exist would damage trust.

## Consequences

- ORP-Standard can ship honestly
- ORP-HighRisk stays blocked until technical and operational gates are passed
- public language remains precise and defensible
